# Sudoku — destek ve gizlilik sayfaları

Bu depo yalnızca App Store'un zorunlu tuttuğu iki sayfayı yayınlar.
Uygulamanın kaynak kodu burada değil.

## Yayına alma (bir kere yapılır)

1. Bu klasördeki dosyaları GitHub'da **public** bir depoya yükle
2. **Settings → Pages → Source: `main` branch, `/ (root)`** → Save
3. Birkaç dakika sonra adresler hazır olur

## App Store Connect'e yazılacak adresler

`<kullanıcı-adın>` yerine kendi GitHub kullanıcı adını koy:

| Alan | Adres |
|---|---|
| Privacy Policy URL | `https://<kullanıcı-adın>.github.io/sudoku-destek/gizlilik-politikasi.html` |
| Support URL | `https://<kullanıcı-adın>.github.io/sudoku-destek/destek.html` |

Depo adını `sudoku-destek` dışında bir şey yaparsan adreslerdeki o
kısmı da değiştir.

## Güncelleme

buraya da kopyala, yoksa iki yer birbirinden ayrılır.
